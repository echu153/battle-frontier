技モーション プロンプト帳

ATB戦闘で技を使ったときに流す動きを、技の種類（物理・魔法・補助・回復）ごとに ChatGPT で作るための頼み方です。攻撃モーションと同じく、キャラの待機の絵1枚とプロンプトで頼みます。

  1. そのクラス・性別の待機の絵を ChatGPT へ添付する（絵をドラッグするか、右クリック→画像をコピーして貼る）
  2. プロンプトをコピーして貼る。 真緑の背景で、横に6コマ並んだ1枚が届く
  3. 届いた画像を public/V2newjob/モーション/ に、行に書いた名前（例：剣士男物理.png）で置く
作成済み 0 / 0

コマがくっついていると、武器や効果の先が切れることがあります。そのときは「コマの間をもっと広く空けて」と頼み直してください。途中で武器が変わったり増えたりしたら「持ち物は6コマ全部で添付の絵と同じにして」、顔や大きさがずれたら「①と同じキャラのまま、大きさと足の位置を全部のコマでそろえて」と頼み直すと戻ります。絵が無い技は、物理と魔法は今の攻撃の動き・補助は光るだけ・回復は補助の動きで代わりに流れます。「作成済み」のしるしはこのブラウザにだけ残ります。
