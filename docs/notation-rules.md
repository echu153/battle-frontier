# バトルフロンティア 表記ルール

2026-07-02 の全ソース棚卸しをもとに制定。**ユーザーの画面に表示される文字列**（JSXテキスト・showMessage/トースト・バトルログ・ヘルプ・AI相談KB）が対象。コード内のコメント・変数名は対象外。

## 用語

| 項目 | 標準表記 | 禁止・注意 |
|------|---------|-----------|
| レベル | `LV`（数値付き: LV30・キャラLV100） | `Lv` `Lv.` は使わない。文章中の「レベルアップ」「レベル上限」等の語は可 |
| クラスレベル | `CLASS LV`（数値付き: CLASS LV30）。その経験値は `CLASS EXP`。ステは「クラスのステ」。ホームの欄は「CLASS：盗賊　LV3/30」・上がったときのログは「⭐ CLASS LEVEL UP！盗賊　LV3 → 4」 | 2026-10-12 ユーザー指示「CLASS にして」（全部の画面）。その前は ClassLV（2026-10-09：はじめ「ジョブレベル（JBLV）」→「CLV」→「普通にClassLVでいい」）。「JBLV」「JBEXP」「CLV」「ジョブLV」「ClassLv」「ClassLV」は使わない（コードの変数名・コメントは対象外） |
| 通貨 | 単語は `Gold`・数値の単位は `G`（例: 100G） | 「ゴールド」は固有名詞のみ可（ゴールドブレード・ゴールドダンジョン） |
| 経験値 | 数値ラベル・ログは `EXP`（例: EXP +10） | 文章中の「経験値」は可。固有名詞「経験値ダンジョン」はそのまま |
| HP/MP | 半角大文字 `HP` `MP` | 全角ＨＰ・「体力」は使わない（説明の注釈は可） |
| ステータス正式名 | 攻撃力・防御力・特殊攻撃力・特殊防御力・素早さ | ステータス画面・デバフログ等の単独表記で使用 |
| ステータス略称 | 攻・防・特攻・特防・速（または攻撃/防御/特攻/特防） | スペースの狭いUI・装備descでの列挙に使用。**同一文・同一ブロックで正式名と略称を混ぜない** |
| 「特殊」単体 | ダメージ種別（物理/特殊）にのみ使う | ステータス名の略として「特殊」単体は使わない |
| エリア番号 | 丸数字 `①〜⑦`（エリア⑤） | 「エリア5」等の半角数字は使わない |
| 施設名 | 賭博場・鍛冶屋・出撃・奈落闘技場・釣り場・交換所・博物館・錬金部屋・かかし修練場 | 「カジノ」等の別名を表示文言に使わない |

## 記号

| 項目 | 標準表記 | 備考 |
|------|---------|------|
| 感嘆符・疑問符 | 日本語文中は全角 `！` `？` | 半角!?は使わない（2026-07-02時点で違反0件） |
| %・+・- と数字 | 半角 `%` `+` `-` `0-9` | 全角％・＋は使わない（ステボーナス表記 例: 特攻+10%）。文章中の「AとBを足す」意味の`＋`（例: 攻撃＋特攻の合計）は全角可 |
| 三点リーダ | `…` | `...` は使わない |
| 矢印 | `→`（数値遷移 100→300 含む） | `⇒` `->` は使わない |
| 区切り | 列挙は `・` または ` / `。装備スロット等の視覚強調は `／` も可 | |
| 括弧 | 日本語文中は全角`（）`を推奨（既存は混在・新規文言から適用） | |
| 状態異常などの発生率 | 必ず `%` で書く（例: `やけど100%` `毒30%`） | **「確定」「必ず」等の言葉に置き換えない**。100%も`100%`と書く（2026-07-31追加） |

## v2cap（バトルフロンティアⅡ）の画面の言葉

2026-11-07 ユーザー「毎回文言調整するの面倒だから、ちゃんとゲーム内の表記ルールは合わせて」。日替わりクエストで直してもらった言い方を、ほかの画面にも同じく使う。

| 項目 | 標準の言い方 | 使わない言い方 |
|------|------------|--------------|
| もらえる量の見出し | `獲得できるEXP` `獲得できるGold`（範囲を出すとき） | 「入るEXP」「入るGold」 |
| もらえる量の説明 | 「与えたダメージが多いほど、獲得できるEXPが増加します」（「〜ほど、獲得できる◯◯が増加します」） | 「入る◯◯が増えます」 |
| もらった量 | 項目名が先：`EXP +251` `Gold +13,650`（挑戦・出撃・塔・デイリーと同じ） | `+13,650 Gold` |
| 通貨 | 画面の文はいつも `Gold` | 画面の文の「金貨」（NPC のセリフは世界観の言葉なので可） |
| 1日1回のものを済ませた | `挑戦済み`（挑戦・日替わりクエスト）・まだなら `挑戦できます`・ボタンは `⚔ 挑戦する` | 「きょうはもう◯◯しました」 |
| 戦闘の時間の行 | 倒した＝`討伐時間`・倒していない（時間切れ・やめた・倒さない戦い）＝`戦闘時間` | 「戦った時間」「修練時間」 |
| 結果の画面 | 遊ぶ人が見て意味のある数だけ（時間・与えたダメージ・もらった量） | 計算のための数（「目安との比」など） |
| 更新の時刻 | `（AM 5：00更新）`（ユーザーの書き方そのまま）。画面ぜんぶが同じ時刻で変わるときは、題の行の右はしに1回だけ（枠ごとに書かない） | 枠ごとに同じ注を繰り返す |
| 待っているあいだのボタン | `読み込み中…` `保存中…` `通信中…`（三点リーダ） | `...` |

- **見張り：** `src/v2cap/lib/notation.test.js` が、画面の文（components・pages・lib・core の文字列と JSX の文）を上のルールと突き合わせる（LV・Gold・半角の%+・…・→・全角の！？・獲得できる◯◯・Gold +N・画面の「金貨」）。ずれた文を書くと `npm test` で落ちる。足し算の意味の「STR×0.3＋INT×0.3」は全角のままでよい（数字の前の＋だけを見る）。
- 2026-11-07 にv2cap の画面をこのテストで洗って直した：待ちのボタンの `...`→`…`（29か所）・スロットと作成の演出の `!`→`！`・ユニーク装備の説明の `％` `＋15` → `%` `+15`（案のシートの控え unique-draft.mjs も同じく）・技の説明の「最大＋50%」・日替わりクエストの `+N Gold`→`Gold +N`。マイナスは「−」（U+2212）と「-」が混ざっているが、ルールが禁じているのは全角の「－」だけなので、そのまま。

## メンテナンス

- 新しい文言を書くときはこのルールに従う。既存文言を編集するついでに周辺の違反も直してよい。
- aiAssistant のキーワード配列（`keywords: ['gold', 'ゴールド', ...]`）はユーザー入力のマッチング用なので、両表記を残すこと（表示文言ではないため対象外）。
- SQLで入れるお知らせ（announcements）の本文もこのルールに従う。

## 2026-07-02 統一時の修正内容（参考）

- `Lv` → `LV`: PvP/組み手/ダンジョン/ペット/プロフィール/ランキング/ステータス詳細のバッジ、メニュー解放表示、Gold/EXPブーストログ 等 約25箇所
- `ゴールド` → `Gold`: 美容院・ペット・鍛冶屋・街画面の「足りません」系と所持金ラベル、賭博場KB 計10箇所
- `％` → `%`: 雷鋼の機神鎧ログ×5ファイル・深淵の水葬・AI相談KB 計9箇所
- `＋Exp/＋EXP` → `+EXP`、チャームdesc `＋10%` → `+10%` 等 計9箇所
- ステ名混在の解消: キャラ作成画面（特殊攻撃→特殊攻撃力）、天穹第7宮説明（特殊攻撃→特攻）、奈落デバフログ（特殊防御→特殊防御力）、イベント装備desc（攻撃力80 防御20→攻撃80 防御20）、街ステータスの「経験値」ラベル→EXP
