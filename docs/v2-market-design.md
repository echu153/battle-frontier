## 確定していること（2026-08-17 ユーザー決定）

- **v2に取引所を作る**（プレイヤー同士で装備とルーンを売買する）
- **強化（`v2_fuse`）ではGoldを使わない。** Goldの主な使い道は**取引所での売買**
- **再出品は「取引してから1週間後」から可能**。それ以外の制限は無い（強化も刻印も自由）
- **ルーンの値段は【ルーン名】の段と、特殊能力が付いているかどうかで変わる**
- **装備の値段は強化値（＋n）で変わる**
- **ルーンを刻んだ装備は出品できない。** **全部外してから**出品する

## ⚠取引所はGoldを減らさない（設計の芯）

プレイヤー同士の売買は**Goldが人から人へ移るだけ**で、世界のGold総量は**1Gも減らない**。
減るのは**手数料**だけ。つまり：

```
Goldが湧く場所 ＝ 素材のNPC売却（これだけ）
Goldが消える場所 ＝ 取引所の手数料（これだけ）
```

**この2つの釣り合いがv2のインフレ対策そのもの**になる。旧版がインフレで作り直しになった経緯を
考えると、ここは最初から意識して数字を置く。

- **湧く量は素材の売値で決まる**（[Goldの作り方](v2-gold-design.md)）
- **消える量は手数料率 × 取引の量**。取引が活発でないとGoldは溜まる一方になる
- ＝**手数料は旧版の20%より高めでよい**（案：**25%**）。あとから下げるのは簡単、上げるのは荒れる

## 出品できるもの

| | 出品 | 備考 |
|---|---|---|
| 装備 | ○ | **ルーンを1つでも刻んでいたら出品できない**（確定）。全部外してから |
| ルーン（未使用） | ○ | 色・ステータス・特殊能力つきの1点もの |
| 素材 | △ | **個数指定でまとめて**。NPC売却があるので、無くても回る（案） |
| スキルの書・魔核 | ✕ | [ユニークボス](v2-unique-boss-design.md)の報酬。**当面は取引不可**（案） |

v2の装備は〈ランク・種類・強化値・ソケットの色〉で**個体差が大きい**ので、
「両手武器で3枠とも緋の個体」のような**厳選品が商品になる**。取引所の主役はここ。

> **解決済み（2026-08-22）**：外す道具＝**刻印除去装置**。**激レア素材5個で1個**作れる
> （`v2_make_unsocket_kit`・エンチャント画面の「ルーン刻印」タブ）。
> 同じ激レア素材はルーンの抽出にも使うので、「外す道具にするか、良いルーンにするか」の択になる。

## 再出品（確定）

- **取引が成立してから1週間（7日）経つと、再び出品できる**
- **それ以外の制限は無い**。買ったその日から**強化もルーンの刻印も自由**
- 旧版のような「帰属（`is_bound`）で取引も加工も永久に禁止」はやめる

実装：

- `v2_inventory` に **`traded_at`**（最後に取引が成立した時刻）を持つ。
  出品できる条件は `traded_at is null or now() - traded_at >= interval '7 days'`
- **判定は1つの述語（SQLの関数）にまとめる**。旧版は帰属の判定を見落とした一括加工が
  購入装備を消す事故を起こしている（`supabase_marketplace_compensation_20260720.sql` で補填）。
  **同じ穴を作らないよう、出品可否を判定する場所を1か所に固定する**
- 画面には**「あと3日で再出品できます」**のように残りを出す（無言で弾かない）

## 値段（案）

**下限**（この値より安く出品できない）と**目安**（相場の参考として一覧に出す）を、
確定した軸＝**ルーンは〈名前の段 × 特殊能力の有無〉／装備は〈ランク × 強化値〉**で作る。

### ルーン

ルーン名は**色 × 合計値の6段**で決まる（`material.js` の `RUNE_NAMES`。合計2%未満＝鋭牙／
10%以上＝修羅）。**段が上がるほど跳ね上げ、特殊能力つきはさらに3倍**にする。

| 段（合計値） | 名前の例（緋） | 下限 | 特殊能力つき |
|---|---|---|---|
| 0（〜2%） | 鋭牙 | 500 | 1500 |
| 1（2〜4%） | 剛撃 | 2000 | 6000 |
| 2（4〜6%） | 破砕 | 8000 | 24000 |
| 3（6〜8%） | 凶刃 | 32000 | 96000 |
| 4（8〜10%） | 撃滅 | 128000 | 384000 |
| 5（10%〜） | 修羅 | 512000 | 1536000 |

### 装備

強化は**1段ごとに基礎ステータスが1.5倍**（`enemies.js` の注記）で伸びるので、
**値段も段ごとに倍にする**。下限 ＝ **ランクの基礎価格 × 2<sup>強化値</sup>**。

| ランク | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 基礎価格 | 200 | 500 | 1200 | 3000 | 8000 | 20000 | 50000 |

- 例：**A級+5** なら 20000 × 32 ＝ **64万G**が下限
- **ソケットの色**（両手3枠が同色など）は下限には入れない。**相場に乗る要素**として一覧で絞り込めるようにする

⚠この表は**取引が始まるまで正しさが分からない**。**下限は「捨て値でばら撒けない」ためのもの**と割り切り、
実際の相場は成約価格の表示に任せる。

## 仕組み（案）

```
v2_market_listings … 出品。inv_id / seller_id / price / listed_at / expires_at / sold_at / buyer_id
v2_inventory        … listed（出品中）/ traded_at（最後に取引が成立した時刻）の列を足す
```

- **RPCだけが所有者・出品状態・`traded_at` を書ける**。旧版と同じく**保護トリガー**を置いて、
  クライアントからの直接UPDATEを弾く（旧版 `supabase_marketplace.sql` の作りを踏襲）
- `v2_market_list(inv_id, price)` … **装備中・出品中・ルーンを刻んでいる・取引から7日未満**は弾く
- `v2_market_cancel(listing_id)` … 出品者だけ
- `v2_market_buy(listing_id)` … **Goldの引き落とし・所有者の移管・出品解除・帰属化を1トランザクションで**
  （旧版と同じ。ここを分けると二重購入が出る）
- **出品期間は7日**。切れたら自動で手元に戻る（案）
- **同時に出せるのは10件まで**（案）

### 価格の下限・上限

- **下限**：上の「値段」の表（サーバー側で計算して弾く）
- **上限**：**極端な高額を弾く**（案：1件1000万G）。RMTと誤操作の両方に効く
- 相場が見えないと売買が成立しないので、**同じ装備の直近の成約価格**を一覧に出す

## 画面（案）

- 街に「取引所」。タブは**買う / 売る / 自分の出品**
- 絞り込みは `browse.js` を流用（ランク・部位・種類・強化値）＋**ソケットの色**、
  ルーンは既にある絞り込み（色・特殊能力の有無・合計値）をそのまま使える
- 並びは「価格が安い順」「新着順」。**装備の性能で並べ替えられる**のがv2の強み

## 実装したもの（2026-08-22）

| | |
|---|---|
| テーブル | `v2_market_listings`（inv_id / seller_id / price / listed_at / expires_at / sold_at / buyer_id）＋ `v2_inventory.traded_at` |
| 出品できるかの判定 | **`v2_can_list()` 1か所**。出品も一覧も必ずここを通す |
| RPC | `v2_market_list` / `v2_market_cancel` / `v2_market_buy` / `v2_market_browse` / `v2_market_sellable` |
| 画面 | 街の「🏪 取引所」。買う／売る／自分の出品 |

- **同じ個体を二重に出せない**（部分ユニーク索引 `v2_market_open_uniq`）
- **買うときは出品の行をロックしてから見る**（同時に買われても片方だけ通す）
- **支払い・売り手への受け取り・所有者の移管・出品の締めは1トランザクション**（分けると二重購入が出る）
- **期限切れは `v2_market_browse` を読むついでに消える**（装備はもともと売り手のものなので、消すだけで戻る）
- 出品中の装備は**買い手からも見える**よう `v2_inventory` の読みポリシーを広げた（出品中の行だけ）

### まだ無いもの

- **ルーンの出品**。テーブルもRPCも装備（`inv_id`）を前提にしている。ルーンを出すなら
  `v2_essences` を指せるようにする改修が要る（下限価格の計算 `runeFloorOf` は先に入れてある）
- **素材の出品**（NPC売却があるので当面は不要と判断）
- 相場の表示は「直近30日の同じ装備＋強化値の最高成約額」だけ。履歴の一覧は無い
