# バトルフロンティアⅡ 職業の個性 — 案（未確定）

⚠**これは案。まだ1つも実装していない**（暗殺者だけ2026-08-19に実装済み）。

「同じ職の技どうしが噛み合って、その職だけの回し方が生まれる」状態を目指す。

暗殺者でやったこと＝**出血を撒く技**と**出血を刈る技**を用意して、2つで1つの流れにした。

同じ考え方で、**職ごとに軸を1つ**決めて、既存の技を数個だけ差し替える案を並べる。


## 要る仕組み（エンジン側）

| 仕組み | 中身 | 実装 |
|---|---|---|
| 溜め（`nextMult`） | 撃つと次の自分の行動の威力が×N。自分は1行動ぶん殴れない | 小 |
| HPコスト（`hpCost`） | 自分の最大HPの n% を払って撃つ | 小 |
| 状態異常特効（`vsAil`） | 相手にかかっている状態異常1つにつき威力+n%（上限あり） | 小 |
| デバフ特効（`vsDebuff`） | 相手に乗っているデバフ1つにつき威力+n%（上限あり） | 小 |
| MPスケール（`mpScale`） | 払ったMP1につき威力+n% | 小 |
| 博打（`variance`） | 威力が lo〜hi の範囲で振れる（当たれば大きい） | 小 |
| 吸収強化（`drainVsAil`） | 相手の状態異常の数だけ吸収量が増える | 小 |
| 両刀（`switchKind`） | 直前に使った技と種別（物理／魔法）が違えば威力+n% | 小 |
| 回復転化（`healToPower`） | 直前に回復した量の n% が次の攻撃に上乗せされる | 中 |
| 専用スタック（`resource`） | 職ごとの資源（気・装填）を貯めて技で消費する | 中 |
| 追撃（`followUp`） | 攻撃のあと確率で追加の一撃が出る | 中 |
| 防御連動（`whileGuard`） | 防御中に撃つと威力+n%（ATB専用） | 小 |
| ゲージ戻し（`gaugeBack`） | 当てるとATBゲージが n 戻る（ATB専用） | 小 |
| 遅延発動（`delay`） | 貼ってから n 秒後に発動する（ATB専用・オートはターンで代用） | 中 |
| 憑依（構え）（`stance`） | 常時効果を1つだけ選んで纏う。切り替えに1行動 | 大 |

- 「小」＝`battle.js` に数行（暗殺者の起爆・命中補正と同じ規模）
- 「中」＝状態を1つ持たせる必要がある（資源・遅延・追撃）
- 「大」＝画面と保存の形にも手が要る（憑依＝構えの切り替え）
