# バトルフロンティアⅡ 職業の個性（2026-08-23 実装完了）

**上位職20職ぶんの「軸」を全部入れ終えた**。この文書はその記録。
数値の正は `src/v2/lib/skills.js`、動きの正は `src/v2/lib/battle.js`。

目指したのは「同じ職の技どうしが噛み合って、その職だけの回し方が生まれる」状態。
最初に暗殺者でやった**出血を撒く技と刈る技で1つの流れを作る**やり方を、20職ぶんに広げた。

⚠**軸は「ある程度」**（ユーザー指定）。職を丸ごと作り直すのではなく、
既存の技を数個だけ差し替えて、その職らしい回し方が1つ生まれれば足りる。

## 20職の軸

| 職業 | 軸 | 仕掛け（キー） |
|---|---|---|
| 侍 | 納刀して斬る | `stance` `whileStance` `foresight` |
| 狂戦士 | HPを燃やして出血を撒く | `hpCostPct` `ailPerHit` `drainIfAil` `frenzy` `hpSteps` |
| 狩人 | 弱った獲物に強い | `lowHpBonus`（追い討ち・絶影狙撃） |
| 暗殺者 | 出血を撒いて刈る | `ail(bleed)` `consumeAil` |
| 元素使い | 直前の技との組み合わせ | `combo`（水氷→雷／地→溶岩／雷→炎）＋元素共鳴 |
| 死霊使い | デバフとドットで削る（吸収は少し） | デバフ各種・`drain:0.25` |
| 聖職者 | 持続回復と、削られる前に押し切る | `regen` `highHpBonus` |
| 異端審問官 | 強化された相手を狩る | `vsBuff` `dispel` |
| サイキッカー | 特防で受けるのに威力はSTR参照 | `srcKind:'phys'`・STR/INTデバフ |
| 体術師 | 地上と空中 | `airUp` `whileAir` |
| 精霊召喚士 | 同じ精霊を呼び続けるほど応える | パッシブ `repeat` |
| 式神使い | 儀式で呪力を練ってから撃つ | `ritual` `useRitual` `ritualStart` |
| 賢者 | オールラウンダー＝どの職の技でも使いこなす | `offClassCut:50`（classBonus） |
| 聖騎士 | 耐久がそのまま火力 | VIT参照・`defRed` |
| 魔法剣士 | 物理と魔法を交互に振る | `switchKind` |
| 魔銃士 | 撃ち続けるほど強くなる | `repeat` ＋ 精密照準（`hitStack`） |
| 武僧 | 状態異常もデバフも効きづらい | `ailResist` `debuffGuard` |
| ビーストレンジャー | 獣の型を切り替える | `form` `formBuff` `formBoost` |
| ギャンブラー | 振れ幅で戦う | `variance` |
| 竜騎士 | 竜気を溜めるほど硬く、解放すると大きい | `chargeUp` `useCharge` |

## 実装した仕組み（battle.js）

| キー | 中身 |
|---|---|
| `lowHpBonus:{max,at}` | 相手のHPが低いほど威力+%。at% 以下で最大 |
| `highHpBonus:{max,at}` | **自分の**HPが高いほど威力+%。満タンで最大 |
| `vsBuff:{per,max}` | 相手に乗っているバフ1つにつき威力+% |
| `dispel:{chance}` | 相手のバフを確率で1つ消す |
| `repeat:{per,max}` | 同じ技を続けて撃つほど威力+%（パッシブ版もある） |
| `switchKind:n` | 直前と種別（物理／魔法）が違えば威力+n% |
| `variance:{lo,hi}` | 威力が lo%〜hi% で振れる（1行動につき1回だけ振る） |
| `combo:{after,mult}` | 直前に使った技が after に含まれていれば威力+% |
| `airUp` / `whileAir:{mult}` | 跳び上がって空中へ（回避+10%）／空中なら威力+%・着地する |
| `ritual:n` / `useRitual:{per}` | 呪力を積む（最大3）／全部使って威力+per%×個数 |
| `chargeUp` / `useCharge:{per}` | 竜気を積む（最大3・軽減率+12%×個数）／全部使って威力+per%×個数 |
| `srcKind` | **威力の参照だけ**を別の型にする（受ける側の防御は kind のまま） |
| `form` / `formBuff` | 獣を呼ぶ＝型が変わる（同じ型なら威力+25%）／型で中身が変わるバフ |
| パッシブ `ailResist` `ritualStart` `formBoost` `hpSteps` `perAct` `hitStack` | 各職の顔になる常時効果 |

## 効果には値段がある

新しい効果を足したら、**必ず値段（`effectPrice` / `relBonus`）も足す**。
値段を付けずに効果だけ足すと「効果がタダ」になり、その技が他職の技の完全上位互換になる。
`skills.test.js` が

- 同じ発動率の帯なら、どの職でも実質価値が揃っているか
- 職業の**中**にも**あいだ**にも完全下位互換が無いか

を突き合わせている。仕組みが違う技どうし（納刀・空中・溜め・振れ幅…）は比べない
＝**役割が違えば数字が上でも下でもよい**という考え方。
