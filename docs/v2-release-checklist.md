## 1. 公開スイッチを立てる前に、必ず塞ぐもの

`V2_PUBLIC = true` にした瞬間、下は**全員に出る**。ここを先に片付ける。

- [ ] **ペットのタブを隠す**（`src/v2/pages/V2Home.jsx` のメニュー③）
  - 育ち具合の保存が localStorage ＝ 仮。しかも**ステが主人公に実数加算される**ので、
    旧版のGoldと同じ改ざんの穴になる。サーバー化まで一般には出さない
  - いちばん軽い手は `isAdmin` のときだけメニューに出すこと（1か所）

  - いまは誰でも押せる形。ATBは試し撃ち場（報酬なし）なので、一般には出さない
- [ ] **旧版からの導線を開ける**（`src/pages/Game.jsx` の「🧪 リメイク版に切替[開発]」）
  - いま `profile?.is_admin` で囲ってある。公開したら `canPlayV2()` を見るように変え、
    ラベルから `[開発]` を外す。ここを忘れると、**既存プレイヤーが入口を見つけられない**
- [ ] **チュートリアルの穴を埋める**（`src/v2/lib/tutorial.js`）
  - いま11個（arena/atb/smith/enchant/storage/tree/base/market/dex/skills/temple）。
    **出撃・デイリー・プロフィールが無い**。いちばん最初に触る画面なので、ここは要る

## 5. 公開後でよいもの（穴として自覚しておく）

- **クライアント申告の残り**。サーバーは上限（EXPは通常11/ボス13・ドロップは戦闘回数以内・
  ランクはエリアの範囲内・Goldは一切受け取らない）を見ているが、
  **「勝ったかどうか」と「何が落ちたか」はクライアントが決めている**。
  改造すれば毎回最大値を申告できる。旧版と同じ強さの検証で、直すなら戦闘そのものをサーバーへ
- **素材ドロップ率upの特殊能力**はクライアント側の確率＝サーバーから検証できない
- **ペット**（サーバー化・SQL・伝説の入手方法・実戦バランス）
- **ユニークボス（ゲリラ）** … 設計メモのみで未実装
- **ATB** … プロトタイプ。ユニークボス専用として作る予定
- **NPCの一覧ページ** … いまは階の一覧から名前が見えるだけ
