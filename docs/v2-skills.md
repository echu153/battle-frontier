# バトルフロンティアⅡ スキル一覧

全28職 × 5個 = 140スキル。正は `src/v2/lib/skills.js`。

## 職業補正（常時発動・枠を使わない）

スキルとは別枠で、**その職業に就いている間だけ**ずっとかかる補正。正は `src/v2/lib/classBonus.js`。
**初期職6職とノーブルには付かない**（通過点なので数字を増やさない／上位職に就いた実感を出すため）。

★スキルは「習得済み」で転職後も残るので、**いまの職業に意味を持たせているのはこの職業補正だけ**。

## パッシブ一覧（上位職21職）

スキルの枠に入れて使う。**複数セットできる**ので、1つ1つの効果は控えめにしてある。
単なる「ステータス+N%」は職業補正の担当にして、パッシブ側は
**ステータスでは書けない挙動**（命中補正・スタック・条件付き強化など）に寄せた。

| 職業 | パッシブ | 効果 |
|---|---|---|
| 侍 | 居合の構え | スキルが不発したとき、代わりに出る通常攻撃の威力が2倍になる |
| 狂戦士 | バーサク | ダメージを与えるたびSTR+3%（最大15%）。不発・通常攻撃・攻撃が外れたときにリセット |
| 狩人 | 鷹ノ目 | 最終命中率+5% |
| 暗殺者 | 隠身 | 回避率+5% |
| 元素使い | 元素共鳴 | 直前と異なるスキルを使うとき、その行動だけINT+10%（重複しない） |
| 死霊使い | 骸の壁 | 戦闘開始時と自分の行動5回ごとに「次に受けるダメージ10%減」を得る（重複しない・1回受けると消える） |
| 聖職者 | 神聖加護 | 自分が回復する量+20% |
| 異端審問官 | 執行本能 | ダメージを与えるたびINT+3%（最大15%）。不発・通常攻撃・攻撃が外れたときにリセット |
| 賢者 | 天啓 | スキルの発動率+5% |
| 聖騎士 | 聖騎士の心得 | VIT+5% |
| 魔法剣士 | 魔導剣術 | INTの20%をSTRへ変換する（そのぶんINTは下がる） |
| 魔銃士 | 精密照準 | 最終クリティカル率+5% |
| サイキッカー | 第六感 | 防御貫通+10% |
| 体術師 | 闘争本能 | HPが減るほどSTRが上がる（最大15%・HP25%で最大） |
| ギャンブラー | ギャンブルボディ | スキルが当たったとき、30%で威力1.2倍・20%で威力0.9倍 |
| 竜騎士 | 竜鱗の加護 | ダメージを受けるとき、10%の確率で25%カット |
| 精霊召喚士 | 精霊共鳴 | 【暫定】INT+5% |
| 式神使い | 式神召喚 | 【暫定】INT+5% |
| ブリーダー | ペット召喚 | 【暫定】STR・INT+3% |
| 武僧 | 心身一如 | 戦闘中1回だけ、相手から受けるデバフを打ち消す |
| ビーストレンジャー | 野性の勘 | 【暫定】AGI+5% |

⚠ 精霊召喚士・式神使い・ビーストレンジャー・ブリーダーの4職は効果を保留中（暫定でステータス補正）。
