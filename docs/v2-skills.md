# バトルフロンティアⅡ スキル一覧

初期職7職 × 5個 ＋ 上位職20職 × 10個 = 235スキル。正は `src/v2/lib/skills.js`。
**2026-08-19に上位職だけ+5**（枠は5つのままなので「候補10個から5つ選ぶ」形になった・[ATB設計](v2-atb-design.md) §3-3）。
**追加ぶんは職業補正の main/sub に合ったステータスも威力に乗る**（例：侍の抜刀＝STR×1.5 ＋ DEX×0.3）。

⚠**いまの職業のスキルでないものは、ダメージ・回復・バフの増減幅・状態異常の付与確率が0.8倍**になる
（2026-08-18・`OFF_CLASS_MULT`）。さらに**消費MPが2倍**（`OFF_CLASS_MP_MULT`）＝想定利用MPの枠を食う。
発動率・防御無視・必中・多段数・パッシブには掛からない。
下の表の数値は**自分の職業のスキルとして使ったとき**の値。

## 効果には値段がある（2026-08-19）

**「フレイムバースト（INT×2.7）」と「幽世ノ門（INT×2.7＋吸収30%）」が同じ発動率**のように、
特殊効果がタダで付いている状態だった＝効果つきの技が他職の技の完全上位互換になっていた。

そこで**効果を倍率へ換算した値段**（`effectPrice`）を決めて、

> 実質価値 ＝ （倍率＋副参照）×多段数 ＋ 効果の値段

が**同じ発動率の帯ならどの職でも同じ**になるように全部付け直した。消費MPも帯で揃えてある。
＝**効果を付けたぶんだけ倍率が下がる**。強さは同じで、違うのは回し方だけ。

| 効果 | 値段（倍率換算） |
|---|---|
| 吸収 | 100%につき**0.80**（吸収30%＝0.24）。★吸収系は火力を控えめにする |
| 防御無視 | 100%につき0.60（50%無視＝0.30） |
| 必中 | 0.15 |
| 確定クリティカル | 0.50 |
| 命中+ | 1%につき0.008 |
| 出血・鈍足 | 付与1%につき0.004（50%＝0.20） |
| 毒 | 付与1%につき0.005 |
| 麻痺 | 付与1%につき0.02（重いので高い） |
| バフ・デバフ | 1%につき0.006（自分に不利なものは割引） |
| 状態異常の起爆 | 倍率そのものが伸びるので**期待値**で計算（2.5スタック想定） |

★数字を足すときは `skillValue()` を通して帯に収める。`skills.test.js` が
「同じ帯なら価値が揃っている」「職業をまたいでも完全下位互換が無い」を突き合わせている。

単なる「ステータス+N%」は職業補正の担当にして、パッシブ側は
**ステータスでは書けない挙動**（命中補正・スタック・条件付き強化など）に寄せた。
