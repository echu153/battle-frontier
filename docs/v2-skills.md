# バトルフロンティアⅡ スキル一覧

初期職7職 × 5個 ＋ 上位職20職 × 10個 = 235スキル。正は `src/v2/lib/skills.js`。
**2026-08-19に上位職だけ+5**（枠は5つのままなので「候補10個から5つ選ぶ」形になった・[ATB設計](v2-atb-design.md) §3-3）。
**追加ぶんは職業補正の main/sub に合ったステータスも威力に乗る**（例：侍の抜刀＝STR×1.5 ＋ DEX×0.3）。

⚠**いまの職業のスキルでないものは、ダメージ・回復・バフの増減幅・状態異常の付与確率が0.8倍**になる
（2026-08-18・`OFF_CLASS_MULT`）。さらに**消費MPが2倍**（`OFF_CLASS_MP_MULT`）＝想定利用MPの枠を食う。
発動率・防御無視・必中・多段数・パッシブには掛からない。
下の表の数値は**自分の職業のスキルとして使ったとき**の値。

## 職業補正（常時発動・枠を使わない）

スキルとは別枠で、**その職業に就いている間だけ**ずっとかかる補正。正は `src/v2/lib/classBonus.js`。
**初期職6職とノーブルには付かない**（通過点なので数字を増やさない／上位職に就いた実感を出すため）。

## パッシブ一覧（上位職21職）

スキルの枠に入れて使う。**複数セットできる**ので、1つ1つの効果は控えめにしてある。
単なる「ステータス+N%」は職業補正の担当にして、パッシブ側は
**ステータスでは書けない挙動**（命中補正・スタック・条件付き強化など）に寄せた。
