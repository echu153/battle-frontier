# 以下は案（未確定）

## 案① 敵の強さは「戦闘力」で置く

v2のダメージ式はスケール不変なので、**敵も戦闘力1つで置けば釣り合いが取れる**。

プレイヤー側の目安：LV1で39、LV100・0転職で534。装備をA級で全枠+0に揃えると+474。

| エリア | 推奨戦闘力 | 通常敵 | ボス | 想定 |
|---|---|---|---|---|
| ① | 50 | 40〜55 | 60 | LV1〜10・装備なし |
| ② | 110 | 90〜120 | 140 | LV20前後 |
| ③ | 190 | 160〜200 | 240 | LV35前後 |
| ④ | 300 | 260〜320 | 380 | LV55前後 |
| ⑤ | 440 | 380〜460 | 550 | LV80前後 |
| ⑥ | 600 | 520〜630 | 750 | LV100＋装備少し |
| ⑦ | 800 | 700〜840 | 1000 | LV100＋C〜B級装備 |
| ⑧ | 1050 | 900〜1100 | 1300 | LV100＋A級装備 or 転職1回 |

## 案② ボスは戦闘力を上げずに「HPへ寄せる」

⚠**v2で戦闘力を上げるとボスは一方的に強くなる**（実測：戦闘力+100差で勝率95%）。
旧版のようにボスのHPを桁違いにする手も使えない（HPは戦闘力8ぶんで換算されるため
そのまま総合力が跳ね上がる）。

そこで **ボスは通常敵と同じくらいの戦闘力のまま、配分をHPとVITへ寄せる**。

```
通常敵  戦闘力300 → HP 800 / STR 55 / VIT 40 / AGI 45 / …（バランス）
ボス    戦闘力380 → HP 2000 / STR 60 / VIT 70 / AGI 40 / …（HPとVITに寄せる）
```

→ **硬くて長期戦になるが、一撃で溶かされはしない**ボスになる。
バフを積む・回復を挟むといった戦い方が意味を持つ帯にできる。

## 案③ 敵もスキルセットを持つ

v2の戦闘ループはプレイヤーと敵で同じ（`runBattle`）。**敵にも5枠のスキルセットを持たせる**のが
いちばん実装が薄い。既存の140スキルから選ぶか、敵専用スキルを足すか。

- 通常敵：1〜2枠（攻撃1つ＋たまに補助）
- ボス：4〜5枠（大技を1つ、発動率低め）

旧版のボスは `specialMove`（天穿雷撃・氷棺葬送など）を持っていたので、**大技の名前は流用できる**。

- 変異ボス・レイド・塔をv2でもやるか
