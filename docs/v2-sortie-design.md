### 敵の作り方

- 敵も「戦闘力」を1つ持ち、`dist`（8ステへの配分%）で散らす。装備と同じ考え方
- **通常敵はボスの3〜4割**。エリア周回は楽で、ボスが壁
- **ボスはHPに40〜45%**を振る（通常敵は24〜38%）。同じ戦闘力でも3〜4倍のHPになり、
  バフを積む・回復を挟む戦い方が意味を持つ長さになる
- 敵のスキルはプレイヤーと同じ形なので `runBattle` がそのまま解釈する。
  通常敵は1〜3枠・ボスは4〜5枠で、**大技の名前は旧版の `specialMove` から流用**
  （天穿雷撃・氷棺葬送・炎獄の審判・天墜滅撃）

# 難易度帯（2026-08-22 ユーザー決定）

**④以降は「1つ倒したら次」ではなく、その難易度帯を全部踏破しないと先へ進めない。**
そのためにエリアを7つ足して**全15エリア**にした。

| 難易度帯 | エリア | 次の帯を開くのに必要な踏破数 |
|---|---|---|
| ① | 始まりの森 | 1 |
| ② | 荒廃した草原 | 1 |
| ③ | 古代の洞窟 | 1 |
| ④ | 蒼海の入り江 / **灼砂の遺丘** | **2** |
| ⑤ | 巨峰山脈 / **常闇の樹海** | **2** |
| ⑥ | 白銀の霊峰 / **雷鳴の断崖** | **2** |
| ⑦ | 煉獄火山 / **腐海の沼獄** / **奈落の坑道** | **3** |
| ⑧ | 蒼天の浮遊城 / **星霜の遺跡** / **深淵の海溝** | **3**（⑧の先は無い） |

- **同じ帯は同格**。戦闘力・ドロップ範囲・素材のレンジ・売値はどのエリアでも同じで、
  違うのは**テーマと敵**だけ（どちらから挑んでもいい）
- 新エリアにも**通常3体・時間帯限定3体・ボス1体**がいる（＝敵105体・素材315種・特殊能力105種）
- 画面に出す番号は**エリアIDではなく帯**。帯に2つ以上あるときだけ「④-2」と枝番を付ける
  （`areaLabel` / `areaFullName`・[`src/v2/lib/enemies.js`](../src/v2/lib/enemies.js)）
- **一度開いた帯は閉じない**。この決定より前に開いていたエリアはそのまま遊べて、
  その帯の新エリアも一緒に開く

## どこで判定しているか

| | 場所 |
|---|---|
| 帯とエリアの対応 | `AREAS[].tier`（enemies.js） |
| 必要踏破数 | `TIER_REQ`（sortie.js）／`v2_tiers`（SQL）※**2か所・v2sql.test.js が突き合わせる** |
| 解放し直す規則 | `unlockNext`（sortie.js）／`v2_unlocked_from_cleared`（SQL・**権威はこちら**） |
| 踏破の記録 | `v2_profiles.cleared_areas`（ボス撃破で積む） |

⚠ 帯の番号は**釣りの副産物・釣りメダル交換所・拠点の素材→資材**でも使う（どれも「エリアN」と
書いてあるが中身は帯N）。エリアIDは9〜15が後ろに付いているだけで難易度順ではないので、
**難易度として数字を使うところは必ず tier を見ること**。

| 帯 | 物理が通りやすい | 特殊が通りやすい | バランス型 |
|---|---|---|---|
| ①②③ | — | — | 始まりの森 / 荒廃した草原 / 古代の洞窟 |
| ④ | 蒼海の入り江 | 灼砂の遺丘 | — |
| ⑤ | 巨峰山脈 | 常闇の樹海 | — |
| ⑥ | 白銀の霊峰 | 雷鳴の断崖 | — |
| ⑦ | 煉獄火山 | 腐海の沼獄 | 奈落の坑道 |
| ⑧ | 蒼天の浮遊城 | 星霜の遺跡 | 深淵の海溝 |

- 倍率は `BIAS_MULT = 1.1`（**与ダメージ+10%**）。そのエリアの敵**全員**（通常・時間帯限定・ボス）に掛かる

# スタミナ／オート出撃（2026-08-22 ユーザー決定）

**スタミナはオート出撃の燃料**。あるあいだは画面が勝手に出撃してくれる。

| | 決めたこと |
|---|---|
| 何に使う | **オート出撃1回につき1消費**。手動（自分でクリック）は**消費しない** |
| 出撃の間隔 | オートも手動も**10秒固定**（10／20の選択は廃止） |
| 切れたら | オートが止まるだけ。**これまで通り自分でクリックして出撃できる** |
| 初期値（最大） | **10** |
| 回復 | **5分に1**・上限は最大値まで。画面を閉じているあいだも溜まる |
| 最大値の伸び | **転職回数**で伸びる。⚠**伸び方はマスク＝画面に出さない** |

## 最大値の伸び方（マスク）

| 転職回数 | 増え方 | そこまでの最大値 |
|---|---|---|
| 1〜29回 | 1回ごとに+1 | 29回で39 |
| 30〜49回 | 3回ごとに+1 | 49回で45 |
| 50〜99回 | 5回ごとに+1 | 99回で55 |
| 100〜299回 | 10回ごとに+1 | 299回で75 |
| 300回〜 | 30回ごとに+1 | 599回で85 |

＝**回すほど「1回にどれだけ連続で放っておけるか」が伸びる**。
1日にこなせる回数を決めるのは回復ペース（5分に1＝1日最大288回）のほうで、
最大値は**まとめて使える幅**（＝溜めておける量）を決める。

## どこに書いてあるか

| | |
|---|---|
| 権威（消費・回復の計算） | `supabase_v2_core.sql` の `v2_stamina_max` / `v2_stamina_roll` / `v2_sortie_settle(p_auto)` |
| 画面側の写し | [`src/v2/lib/stamina.js`](../src/v2/lib/stamina.js) |
| 突き合わせ | `src/v2/lib/v2sql.test.js`（片方だけ直すと落ちる） |
| 画面 | [`src/v2/components/V2Sortie.jsx`](../src/v2/components/V2Sortie.jsx) |

- 持ち方は `v2_profiles.stamina`（いまの値）と `stamina_at`（最後に数え直した時刻）の2列。
  経過時間から足すので、**端数（4分59秒ぶん）は次へ繰り越す**
- 満タンのあいだは `stamina_at` を `now()` にしておく＝止まっているあいだに溜め込まない
- オートは**リロードで再開しない**（勝手に走ってスタミナを溶かさないため）
- 武器の進化のポップアップが出ているあいだはオートを止める（選ばせてから続ける）
