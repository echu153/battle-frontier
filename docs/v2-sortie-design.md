プレイヤーの戦闘力 ＝ 本体（534＋転職×100）＋ 装備（基礎×1.5^強化×7.9）。

⚠**ボスの戦闘力は「目安の合計」そのままではない。** HPへ寄せたボスは同じ戦闘力でも

係数がエリアごとに違うのは、ボスの配分（攻撃寄りか耐久寄りか）で難度が変わるため。

### 敵の作り方

- 敵も「戦闘力」を1つ持ち、`dist`（8ステへの配分%）で散らす。装備と同じ考え方
- **通常敵はボスの3〜4割**。エリア周回は楽で、ボスが壁
- **ボスはHPに40〜45%**を振る（通常敵は24〜38%）。同じ戦闘力でも3〜4倍のHPになり、
  バフを積む・回復を挟む戦い方が意味を持つ長さになる
- 敵のスキルはプレイヤーと同じ形なので `runBattle` がそのまま解釈する。
  通常敵は1〜3枠・ボスは4〜5枠で、**大技の名前は旧版の `specialMove` から流用**
  （天穿雷撃・氷棺葬送・炎獄の審判・天墜滅撃）

## 進行まわり（確定・実装済み）

正は [`src/v2/lib/sortie.js`](../src/v2/lib/sortie.js)。**旧版と同じ仕組み**で、
数値で変えたのは**ボスの出やすさだけ**（2026-08-14 ユーザー決定）。

| | 旧版 | v2 |
|---|---|---|
| エリア解放 | そのエリアのボス撃破で次が開く（⑦撃破で⑧） | **同じ** |
| ボスの出方 | 通常戦闘のたび遭遇率+0.5%・ボスに当たると0へ戻る | **同じ仕組み・+0.3%へ** |
| ボスまでの平均 | 18.4回 | **23.6回** |
| EXP | 通常8〜11・ボス13 | **同じ** |
| Gold | 敵ごとの設定値（スライム20〜ウラノス60000） | **同じ** |
| クールタイム | 20秒（10秒モードはEXPとGoldが半分） | **10秒／20秒を選べる。取得量はどちらも同じ** |
| 装備の落ちる確率 | 通常3%＋レア10% | **10秒=3% / 20秒=4%** |

ボスはピティ方式（引くほど確率が上がり、当たるとリセット）なので
**「何十回引いても出ない」事故が起きない**。旧版の作りをそのまま踏襲している。

⚠旧版にあった「キャラクターLV100まで経験値1.5倍」は、v2に  が無いので入れていない。

### 装備ドロップ（確定・実装済み）

**部位も種類も完全ランダム**。ただし**1時間ごとに「落ちやすい部位」が入れ替わる**。

| | |
|---|---|
| 部位 | 武器 / 頭 / 鎧 / 腕 / 足 / アクセ の6つ |
| その時間の部位 | 重み**2倍**（28.6%）。ほかは14.3%ずつ |
| 切替 | **毎時0分**。6部位なので6時間で一周する |
| 決まり方 | JSTの時刻から算出＝**全員に共通**で、先の予定も出せる（） |
| 種類 | その部位の中から完全ランダム（武器10種／防具3系統／アクセ4種） |
| ランク | エリアごとの分布（上の表） |

装備カタログは [`src/v2/lib/equipment.js`](../src/v2/lib/equipment.js)（**182本**）。
**落ちる確率は 10秒モードで3%・20秒モードで4%。**
20秒のほうが1回あたりは高いので、10秒の効率2倍がいくらか相殺される
（時間あたりでは 10秒=0.30%/秒・20秒=0.20%/秒 で、まだ10秒が1.5倍有利）。
