## 0. 何を作って、何を作らないか

いまのv2の戦闘（[battle.js](../src/v2/lib/battle.js) の `runBattle`）は
**「最初から最後まで一気に回してログ配列を返す純関数」**で、プレイヤーの入力が入る余地がない。
ATBは「時間で溜まる → 予約した行動が出る → また溜まる」なので、**一気に回せない**。
＝**ループの外側だけを新しく作る**ことになる。

| 層 | 中身 | ATBで |
|---|---|---|
| ステータス組み立て | `createSide`（職業補正・パッシブ・エンチャント・ルーン） | **そのまま流用** |
| ダメージ・命中・クリ・軽減 | [combat.js](../src/v2/lib/combat.js) 全部 | **無改修** |
| 状態異常・出血毒 | [ailments.js](../src/v2/lib/ailments.js) | **ATB用の別表を持つ**（§2・オート戦の定数は触らない） |
| ログの文面 | [battleLog.js](../src/v2/lib/battleLog.js) | **そのまま流用** |
| **戦闘の進行** | `runBattle` のターンループ | **ここだけ新規（`src/v2/lib/atb.js`）** |

**ダメージ計算を二重に書かない**のが最重要（＝バランス調整の正が1か所に残る）。
ATB側が持つのは**ゲージ・予約・時間の刻み**だけ。

### 既存コードに要る改修（案・小さい）

- `battle.js` の `takeAction(me, foe, rng, log)` → **第5引数でスキルを指定できるようにして export**
  （省略時はいままで通り `findSlot` で自動選択＝オート戦闘の挙動は1ミリも変わらない）
- `tickAil` / `tickRegen` を export（ATB側の刻みから呼ぶ）
- **バフに残り時間を持たせる**（§2）。いまの `side.buffs` は `{ ステ: % }` だけなので、
  ATB用に `{ ステ: [{ pct, until }] }` を持つ形へ広げる。**オート戦闘側は無改修で通す**
- `runBattle` 本体・`combat.js`・スキルデータは**無改修**

## 1. ゲージと予約（確定＋案）

### 溜まり方（案）

- ゲージは **0 → 100** で1行動ぶん
- **毎秒の充填量 = 25 × R**（＝等速なら**4秒で1行動**）
- R ＝ **(自分のAGI ÷ 相手のAGI) の AGI_EFFECT 乗**を **0.75〜1.5** でクランプ
- **AGI_EFFECT＝0.35**（＝AGI差の効きを決める**つまみ**）

| AGI比（自分÷相手） | R | 1行動あたり |
|---|---|---|
| 0.44以下 | 0.75 | 5.3秒 |
| 0.5 | 0.78 | 5.1秒 |
| 1.0 | 1.0 | 4.0秒 |
| 2.0 | 1.27 | 3.1秒 |
| 3.0 | 1.47 | 2.7秒 |
| 3.2以上 | 1.5 | 2.7秒 |

**AGI_EFFECT で効き方をまるごと変えられる**（インフレしても直すのはここ1か所）：

| AGI_EFFECT | AGI2倍のとき | AGI5倍のとき | 意味 |
|---|---|---|---|
| 1.0 | 2.00倍速 | 1.5倍速（上限） | 比がそのまま＝効きすぎ |
| 0.5（平方根） | 1.41倍速 | 1.5倍速（上限） | 2026-08-19の昼まではこれ |
| **0.35（いま）** | **1.27倍速** | **1.5倍速（上限）** | AGIは効くが支配しない |
| 0.2 | 1.15倍速 | 1.38倍速 | ほぼ味付け程度 |
| 0 | 1.00倍速 | 1.00倍速 | AGIは速さに無関係 |

⚠**なぜインフレに強いか**：Rは**絶対値ではなく相手との比**で決まるので、
AGIが100→10000になっても、相手も一緒に伸びていれば速さは変わらない。
効くのは**差が開いたとき**だけで、その効き方が AGI_EFFECT。さらに 0.75〜1.5 のフタがあるので、
どれだけ差が開いても**行動回数の差は2倍まで**にしかならない。

⚠**2026-08-19 の調整履歴**：最初は 20×√（0.5〜2.0）＝等速5秒・最大4倍差 →
相手が遅すぎたので 25×√（0.75〜1.5）＝等速4秒・最大2倍差 →
それでもAGIが効きすぎるため**指数を 0.5 → 0.35 に下げ、つまみとして切り出した**。

- 平方根とクランプを噛ませるのは、オートの追加行動（`extraActionRate`＝AGI比10倍で+50%が上限）と
  **「AGIを伸ばすほど行動が増えるが頭打ちがある」という効き方を揃える**ため。
  ATBは差がそのまま行動回数になるので、素の比のままだと**AGI一強**になる
- **麻痺＝ゲージが5秒止まる**／**鈍足＝R が0.8倍**（＝状態異常がATBで素直に化ける）

### 予約（確定・アクティブ方式）

**時間は止まらない。** その代わり、**ゲージが溜まりきる前から次の行動を選んでおける**。

- 選んでおいた行動は、**必要ゲージに届いた瞬間に自動で発動**する（＝もたついて損をしない）
- 予約は**満タンになるまで何度でも変更できる**
- **予約していないまま必要量に届いたら、「デフォルト行動」が自動で出る**（確定）。
  ＝**ゲージが満タンで止まって時間を捨てることはない**。ぼんやりしていても最低限は殴り続ける
- **デフォルト行動は戦闘前に自分で決める**（確定）：**通常攻撃**、または**スキル枠から選んだ1つ**
  - デフォルトにスキルを選んだ場合、待つ長さは**そのスキルの必要ゲージ**になる
    （例：強撃をデフォルトにすると、放っておくと6.5秒ごとに強撃が出る）
  - **MPか使用回数が尽きたら通常攻撃へ落ちる**（＝手が止まらない）
- 100を超える技（例：強撃130）を予約すると、**130に届くまで自動的に待ってから出る**。
  ＝「大技を予約して溜める」あいだは小技を撃てない**トレードオフ**が生まれる。これがATBの駆け引きの本体

## 2. バフ・デバフ・状態異常は「秒」で管理する（確定＋案）

⚠**いまのv2のバフは持続時間を持っていない**（`防御態勢 VIT+50%（重ねがけ可）` は戦闘が終わるまで永久に乗る）。
持続を持っているのは状態異常だけ。＝**バフに時間を持たせるのは新しい仕組み**になる。

### バフ・デバフの持続＝強さで決まる（案）

> 持続（秒） ＝ **3000 ÷ 効果の合計%**（**30〜120秒**でクランプ）

「効果の合計%」＝そのスキルが動かすステータスの%を絶対値で足したもの
（オールインの STR+50%・VIT-30% なら 80）。

| スキル | 効果 | 合計% | 持続 |
|---|---|---|---|
| 気合い（ノーブル） | STR+15% | 15 | **120秒**（上限） |
| シルフ（精霊召喚士） | AGI+25% | 25 | **120秒** |
| 駆け足（弓使い） | AGI+30% | 30 | **100秒** |
| 身構える（ノーブル） | VIT+35% | 35 | **85秒** |
| ブラッティロア（狂戦士） | STR+40% | 40 | **75秒** |
| 残心（格闘家） | DEX・AGI+20% | 40 | **75秒** |
| 防御態勢（戦士） | VIT+50% | 50 | **60秒** |
| 明鏡止水（侍） | STR+30%・DEX+20% | 50 | **60秒** |
| 狩猟本能（狩人） | STR・AGI+30% | 60 | **50秒** |
| 影歩き（暗殺者） | AGI+40%・DEX+20% | 60 | **50秒** |
| 魔剣開放（魔法剣士） | STR・INT+35% | 70 | **43秒** |
| 祈りの結界（聖職者） | VIT+50%・INT+20% | 70 | **43秒** |
| オールイン（ギャンブラー） | STR+50%・VIT-30% | 80 | **38秒** |

- 中央値が**60秒前後**＝「基本1分ぐらい」に収まり、**強いバフほど短い**（確定事項どおり）
- **新しい数値表を作らなくていい**（既存のスキルデータから機械的に出る）＝
  スキルを足してもATB側は何もしなくてよい
- **デバフ（相手に掛けるもの）は上限60秒**にする（案）。デバフは攻撃技のおまけとして
  撃つたびに積めるので、上限120秒だと積み上がりすぎる
  （防御崩し VIT-15% を連打するだけで相手のVITが実質半分のまま固定される）
- **重ねがけは1回ごとに別の残り時間を持つ**（案）。掛け直しで全部の時間がリセットされるのではなく、
  **古いものから順に切れていく**＝維持したければ撃ち続ける必要がある
- 定数 3000 は案。**2000にすると全体が2/3の長さ**（防御態勢40秒）になる

### 状態異常（案）

「1ターン〜30秒」の帯で置き直す。ダメージが入る間隔は**5秒ごと**で統一する。

| 状態異常 | オート戦 | ATB戦 | 中身 |
|---|---|---|---|
| 麻痺 | 1ターン | **5秒** | ゲージが止まる。これ以上長いと理不尽 |
| 回復阻害 | 3ターン | **15秒** | 回復量が下がる |
| 出血 | 3ターン | **20秒** | 5秒ごとに現在HPの1%×スタック（最大5） |
| 毒 | 4ターン | **30秒** | 5秒ごとに最大HPの3%＝6回で18%（オート戦は12%） |
| 鈍足 | 4ターン | **30秒** | AGI-20%＝ゲージの溜まりが0.8倍 |
| 継続回復（regen／mpRegen） | nターン | **n × 5秒** | 5秒ごとに1回 |

⚠**オート戦の値は触らない**（`ailments.js` の定数はそのまま）。**ATB側が別の表を持つ**形にする。
＝出撃・アリーナ・ダンジョンのバランスには一切影響しない。

⚠**バフが60秒級になったので、1挑戦が40〜80秒だと「最初に撒けば最後まで持つ」**＝
掛け直しの駆け引きが薄くなる。**1挑戦を90〜150秒に伸ばす**と「後半に切れるので撒き直す」が生まれるが、
ユニークボスは1時間あたりの挑戦回数が減る（＝DPSチェックの間隔とボスHPで釣り合わせる）。
**実装して触ってから決める。**

### 1挑戦が終わったら全部消える（確定）

勝っても負けても時間切れでも、**その挑戦で積んだバフ・デバフ・状態異常は全部リセット**。
次の挑戦は素の状態から始まる。

## 3. スキルの発動率（proc）→ 必要ゲージ（確定）

**ATB戦では `proc`（発動率）を使わない。** 自分で選んだ技が空振りするのはストレスなので、
**「不発する代わりに溜めが長い」**へ読み替える。

> 必要ゲージ ＝ **100 + (100 − proc) × 2**

| proc | 必要ゲージ | 等速での溜め |
|---|---|---|
| 100%（補助・防御態勢など） | 100 | 5.0秒 |
| 95%（通常技） | 110 | 5.5秒 |
| 85%（主力） | 130 | 6.5秒 |
| 75%（切り札） | 150 | 7.5秒 |
| 60%（敵の大技） | 180 | 9.0秒 |

- **新しい数値表を作らなくていい**（既存の proc から機械的に出る）＝スキルを増やしてもATB側は何もしなくてよい
- 「強い技ほど出しにくい」という設計意図が**そのまま残る**（不発ではなく待ち時間に変わるだけ）
- `uses`（使用回数3回）は**据え置き**。撃ち切ると通常攻撃だけになる＝「10行動前後で弾切れ」という
  ユニークボスのDPSチェックの前提を壊さない
- `priority`（先制値）はATBでは意味を失うので**無視**する
- 通常攻撃は**必要ゲージ100で常に選べる**
- 係数の 2 は案。1.5にすると大技が回りやすく、3にすると小技の回転が有利になる。**実測して決める**

⚠この読み替えにより、ATB戦は**オート戦とは別バランス**になる（不発ぶんの期待値が消えて**火力が上がる**）。
ユニークボスのHP式は**ATB前提で測り直す**（§7）。

## 4. 画面（案）

```
┌────────────────────────────────┐
│  サドニス                HP ██████████░░ 62%      │
│  ATB ███████░░░░░  ← 溜まりきると大技が来る        │
│  【デバフ】防御崩し ███░░ 8s ／ 毒 ██████░ 14s     │
├────────────────────────────────┤
│  ログ（既存の V2LogLine をそのまま流す）            │
├────────────────────────────────┤
│  えちゅ   HP ████████░░   MP ██████░░░░            │
│  ATB ████████░░ 82/130  ← 予約中：強撃             │
│  【バフ】防御態勢×2 ██████░ 13s ／ 気合い ██░ 4s   │
│  ［強撃 130］［防御崩し 110］［防御態勢 100］       │
```

- **予約中の技はボタンが光る**。ゲージのバーにも「82/130」と必要量を出す
- **デフォルト行動**は戦闘中でも変えられる（＝オートに近い運用と手動を行き来できる）
- **バフ・デバフは自分と敵の両方**にバーで並べる（残り秒つき）。ここがこの戦闘の情報の要
- 敵のゲージも出す。「あと2秒で大技が来るから、いま防御態勢を予約する」が成立する
- ログは既存の `buildBattleLog` の文面をそのまま1行ずつ流す（出撃と文体が揃う）
- **1挑戦は40〜80秒**を狙う（オートの10ターン相当＝10行動前後）

## 5. リアルタイム特有の穴と対策（技術・確定寄り）

| 穴 | 対策 |
|---|---|
| タブを裏に回すと `setInterval` が絞られる | dt は `Date.now()` の差分で取り、**1フレーム250msでクランプ**。裏に回すと実質止まる＝**損する側**なので悪用にならない |
| 回線・端末の速さで有利不利が出る | **予約方式**がこれを消す（§1）。溜まりきる前に選んでおけるので、反応の速さを競わせない |
| 途中でリロードされた | **申告しない＝与ダメ0**。損するだけなので穴にならない |
| 与ダメの申告を改ざんされる | ユニークボスは**与ダメの蓄積がそのまま報酬**になるので、RPC側で**1挑戦あたりの上限（戦闘力から出す理論値）でクランプ**する。※これはATBだから増える穴ではなく、いまの出撃（`v2_sortie_settle`）も同じクライアント申告 |

## 6. オートとの併存（確定）

ATB戦の画面に**［オート］トグル**を置く。ONのあいだはゲージが必要量に届いた時点で
**既存の `findSlot` と同じ順番で自動的に撃つ**（＝いまのオート戦闘とほぼ同じ挙動になる）。

- ながら勢・操作したくない人を切らない（ユニークボスは1時間で何十回も殴るコンテンツ）
- **手動のほうが強い**（撃ち分け・大技の溜め・バフの掛け直し）。ただし差は**1.2倍程度**に抑えて、
  オートが死に選択肢にならないようにする

## 7. ユニークボス側で作り直しになるところ

[ユニークボス設計](v2-unique-boss-design.md) は**オート前提・バフ持ち越し前提**で数字を置いてあるので、
今回の確定でそのままでは通らない。**ATBを実装したあとに測り直す**。

| 向こうの記述 | 今回の確定との関係 |
|---|---|
| 「バフ／デバフは挑戦をまたいで蓄積」（確定事項） | **上書き。1挑戦で消える**（§2） |
| 「後半の挑戦ほど1回で削れる」＝バフ蓄積が前提 | **成立しなくなる**。1挑戦の与ダメは最初から最後までほぼ一定になる |
| ボスHP ＝ 96 × P × (P/2000)^0.22（想定130挑戦） | **測り直し**。バフ蓄積ぶんの伸びしろが消える一方、**不発が消えて火力が上がる**（§3）ので、上下どちらに振れるかは実測しないと分からない |
| 10ターンごとのDPSチェック | **秒に読み替える**（例：50秒ごと）。役割（削れない挑戦を早く畳む）は変わらない |

## 8. プロトタイプ（2026-08-19 実装済み）

**ホームの ⏱ ATB[開発] タブ**から試し撃ちできる（エリアと相手を選んで戦うだけ・**報酬なし／サーバーへ何も送らない**）。

| 物 | 中身 |
|---|---|
| [`src/v2/lib/atb.js`](../src/v2/lib/atb.js) | ゲージ・予約・デフォルト行動・バフの残り秒・状態異常の別表・時間の刻み |
| [`src/v2/lib/atb.test.js`](../src/v2/lib/atb.test.js) | 15本（必要ゲージ／AGI比／バフ持続／予約とデフォルト／麻痺／毒／裏タブ対策／決着） |
| [`src/v2/components/V2Atb.jsx`](../src/v2/components/V2Atb.jsx) | 画面。HP・ATB・バフ／デバフのバー、コマンド、デフォルト行動、オート |
| [`battle.js`](../src/v2/lib/battle.js) の改修 | `takeAction` に `{ idx, noProc, noParalyze }` を足して export しただけ（**省略時の挙動は前と同一**） |
