# Twitch 複窓ツール（Java）

Twitch の URL を貼るだけで、複数の配信をタイル状に並べて同時に見られるツールです。

- Java の操作画面に URL を貼る → ブラウザに複窓ページが開き、枠が増える
- ブラウザのページで `Ctrl+V` しても増える（どちらで操作しても自動で同期）
- 画面サイズに合わせて 16:9 の枠がいちばん大きくなるように自動で並ぶ
- 1 枠だけ大きく表示（残りは横か下に小さく並ぶ）
- 音を出す枠をワンクリックで切り替え、チャット欄はタブで切り替え
- 一覧は保存され、次に起動したときも同じ並びで開く

## 必要なもの

- Java 17 以上（`run.bat` / `run.sh` を使う場合は JDK）
- いつも使っているブラウザ（Chrome / Edge / Firefox など）

## 起動のしかた

**Maven なし（いちばん手軽）**

- Windows: `run.bat` をダブルクリック
- Mac / Linux: `./run.sh`

**Maven で jar を作る場合**

```sh
mvn package
java -jar target/twitch-multiview.jar
```

起動すると操作画面とブラウザの複窓ページ（`http://localhost:17878/`）が開きます。

## 使い方

URL は次のどれでも追加できます。

| やり方 | 説明 |
| --- | --- |
| 操作画面の入力欄に貼って Enter | 改行・スペース区切りで複数まとめて貼ってもOK |
| 操作画面の一覧で `Ctrl+V` / URL をウィンドウにドラッグ＆ドロップ | そのまま追加 |
| 「コピーした Twitch の URL を自動で追加」にチェック | ブラウザで URL をコピーするだけで追加 |
| 複窓ページのどこかで `Ctrl+V` / 上の欄に貼る | そのまま追加 |

文章ごと貼った場合（例:「配信中！ https://www.twitch.tv/xxx #タグ」）は、`twitch.tv` の URL だけを拾います。

### 読める URL

| 種類 | 例 |
| --- | --- |
| ライブ配信 | `https://www.twitch.tv/チャンネル名`、`チャンネル名`、`@チャンネル名` |
| アーカイブ | `https://www.twitch.tv/videos/123456789`（`?t=1h2m3s` の再生位置も引き継ぐ） |
| クリップ | `https://clips.twitch.tv/ID`、`https://www.twitch.tv/チャンネル名/clip/ID` |

`m.twitch.tv` やポップアウトチャットの URL、埋め込みプレイヤーの URL（`player.twitch.tv/?channel=…`）も読めます。

### 複窓ページの操作

枠にマウスを乗せると上にボタンが出ます。

| ボタン | はたらき |
| --- | --- |
| 🔊 | この枠の音だけ出す（ほかはミュート）。もう一度押すと消音 |
| ◀ ▶ | 並び順を入れ替える（再生は止まりません） |
| ⤢ | この枠を大きく表示。`Esc` か「均等に並べる」で戻る |
| ✕ | 枠を閉じる |

上のバーには「全ミュート」「チャット（表示切替）」「全画面」「▲（バーを隠す）」があります。

## 起動オプション

```
java -jar twitch-multiview.jar [オプション] [URL かチャンネル名 ...]
```

| オプション | 説明 |
| --- | --- |
| `--port <番号>` | 使うポート（既定 17878。使用中なら次の番号を順に試す） |
| `--nogui` | 操作画面を出さず、ブラウザのページだけで操作する |
| `--no-browser` | 起動時にブラウザを開かない |
| `--no-save` | 一覧を保存しない・前回の一覧を読まない |

一覧は `~/.twitch-multiview/streams.txt`（Windows は `C:\Users\<名前>\.twitch-multiview\streams.txt`）に 1 行 1 URL で保存されます。

## しくみと注意

- Java の中に小さな Web サーバーを立て、Twitch 公式の埋め込みプレイヤーを並べたページをブラウザで開いています。
  Java 標準のブラウザ部品（JavaFX WebView）では Twitch のプレイヤーが再生できないため、普段のブラウザを使う形にしています。
- サーバーは自分の PC（127.0.0.1）からの接続しか受け付けず、ほかのサイトから一覧を書き換えることもできません。
- Twitch の埋め込みは「埋め込み先のサイト名」を `parent` で伝える決まりがあるため、ページは `localhost` で開きます。
- ブラウザの自動再生の制限で、最初は音が出ないことがあります。その場合はプレイヤーを一度クリックしてください。
- 枠が小さすぎる（目安 400×300 未満）と、Twitch 側の制限で自動再生されないことがあります。
- Java のツールを閉じても再生中の配信はそのまま見られますが、追加・同期はできなくなります。

## 開発

```sh
mvn test      # URL の読み取り・一覧・サーバーのテスト
```

| ファイル | 役割 |
| --- | --- |
| `Main.java` | 起動・オプション |
| `TwitchUrlParser.java` | 貼られた文字列から配信を読み取る |
| `MultiViewState.java` | 配信の一覧（並び順・保存） |
| `MultiViewServer.java` | 複窓ページと API を配る HTTP サーバー |
| `ControlPanel.java` | Swing の操作画面 |
| `resources/twitchmultiview/multiview.html` | 複窓ページ（レイアウト・プレイヤー・チャット） |
